The zero-shot development baseline scored 0.8 on the 10 development rows. Both four-example candidates scored lower: seed 7 at 0.6 and seed 21 at 0.7. Seed 21 was selected. On the 20 held-out test rows it scored 0.75.

Seed 21’s examples are one airfare utterance that contains “fare”, one airline utterance about airlines between cities, and two ground-service utterances. They include no abbreviation example and no flight example. On development, “what airline is ac” changed from the correct airline label to abbreviation. Both the baseline and seed 21 still miss “what is restriction ap 80”: the gold label is abbreviation, and the prediction is restriction, because the utterance asks what a code means while using the word “restriction”. Seed 7 dropped further. Its examples turned the two morning flight requests into flight_time, and its first example, “what does the airline code dl stand for”, is labeled airline, which sits on that same boundary.

Development and test can differ because they hold different sentences, and because one miss moves development accuracy by 0.1 but test accuracy by 0.05. The test set repeats the restriction-code miss and adds boundaries the four examples never show: “cheapest round trip fares” predicted cheapest, “list airlines flying from seattle to salt lake city” predicted flight, and two route questions predicted flight_no. Selection used only the development score, so those test patterns did not affect the choice.
